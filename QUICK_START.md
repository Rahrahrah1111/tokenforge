# 🚀 Quick Start - Automated API Setup

## The Easiest Way (30 seconds)

1. **Open `quick_setup.html` in your browser**

2. **Click the "Get Free Key →" links** for each service

3. **Sign up and get your API key**

4. **Just copy the key** - it will be automatically detected and saved! ✨

5. **Done!** Refresh the page and you're ready to go.

---

## Alternative: Full Automation

### Step 1: Install
```bash
npm install
```

### Step 2: Run
```bash
npm run setup
```

The script will:
- ✅ Open browser windows for each service
- ✅ Guide you through signup
- ✅ Auto-detect API keys
- ✅ Save them automatically
- ✅ Generate ready-to-use files

### Step 3: Use
Copy the generated `api_keys_localStorage.js` into browser console on the A.V.A. page.

---

## How Auto-Detection Works

The auto-detector monitors:
- 📋 **Clipboard** - When you copy a key
- 📄 **Page content** - Keys visible on the page
- ⌨️ **Input fields** - Keys you type

Just **copy/paste anywhere** and it's automatically saved!
